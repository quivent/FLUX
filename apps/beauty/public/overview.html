One studio H100 (80 GiB): FLUX.1-dev BF16 + Qwen3.8-27B FP8 witness + Pixtral-12B W4A16 critic + DINO/SigLIP gates. Governor (Gemma) remote by default. Total 80.0 GiB exactly — do not add another resident model.

remote-qwen → h100-remote-witness

Studio H100 keeps FLUX + Pixtral + gates. Qwen witness moves to a dedicated clean machine (set MOJ_VISUAL_WITNESS_URL). Gemma remote. Kontext optional, off by default.

distributed → h100-distributed-atelier

Expanded studio (FLUX + Pixtral + gates + Kontext) plus a dedicated BF16 Qwen witness machine and a dedicated Gemma governor machine. Witness and critic fan out independently; evidence converges at Gemma.

The generation loop

Pipeline

beauty_pipeline.py · latency-first

One frame at a time

One resident FLUX worker renders a single 512×512 frame at 18 steps, then publishes it immediately.

One bounded advisor per frame

Pixtral gets first refusal because it sees pixels; Qwen is the vision/text fallback; Gemma the text-only fallback. Exactly one advisor is called per frame.

Dead advisors cool down

An unreachable endpoint cools down for 30 seconds instead of taxing every render. No judge stalls the loop.

State is durable

Exposed at /api/beauty/pipeline, written to .fluxd/protocol_stream_gpu3.json. Restart-safe; no false success when a judge is unreachable.

Fixed geometry
frame 512 × 512 steps 18 guidance 3.5 (default) publish immediate advisors 1 per frame, timeout-bounded cooldown 30 s per dead endpoint

Non-negotiable

Invariants

Pixtral never leaves the studio

Pixtral is local to the FLUX studio in every Beauty profile. Moving Qwen remote must remove its local VRAM reservation and suppress its local vLLM container.

Remote judges speak OpenAI

Remote endpoints must expose OpenAI-compatible /v1/models and /v1/chat/completions. Cross-machine traffic uses HTTP + auth. Unix sockets never cross machine boundaries.

A failed gate is not a deployment

A failed witness, critic, or governor health gate is not a successful Beauty deployment. First bring-up provisions GPU 0 only; GPU 1 is untouched until GPU 0 passes.

The operator owns the verdict

Operator words are persisted verbatim. Machine scores rank the full slate but never hide or automatically kill a candidate. Gemma is never the final gate.

Keep the brief and the source frame

The prompt and collection are fixed before a run. The archive stores the rendered image, not an interpolated or quietly repaired substitute.
