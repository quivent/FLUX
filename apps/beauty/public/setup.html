Setup

The whole Beauty Protocol Suite — the server, the generation loop, the EGRL eye-gate, the hardware profiles, and this web surface — ships as one bundle. Unpack it, run one script, and you have a working install.

The whole thing

Three steps

Unpack the bundle

tar -xzf beauty-suite-1.0.0.tar.gz cd beauty-suite-1.0.0

Install & verify

./bootstrap.sh

Lays the suite down, seeds the EGRL ledgers, points the flux binary at the bundle, and verifies. No root, no system packages.

Serve it

./bootstrap.sh --serve # → http://127.0.0.1:7863/overview

Add --publish to map beauty.influx.vision through gemstone in the same step.
